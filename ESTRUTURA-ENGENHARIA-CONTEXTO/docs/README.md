# Documentação Formal

Este diretório contém a documentação formal do projeto gerada pelo SDLC Guide.

## Documentos Gerados

- **URS.md** - User Requirement Specification
- **architecture.md** - Software Architecture Document  
- **test_plan.md** - Plano de Testes

## Como Usar

Execute `python3 sdlc_guide.py` na raiz do projeto para gerar automaticamente estes documentos baseados nas suas respostas.
