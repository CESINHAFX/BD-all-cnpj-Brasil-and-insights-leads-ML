# Conteúdo Web (URLs)

Este diretório contém conteúdo de URLs convertido em texto.

## Estrutura

```
/urls
  ├── artigo_blog1.md
  ├── tutorial_site.md
  └── README.md          # Este arquivo
```

## Como Adicionar Conteúdo

1. Use ferramentas como `requests` e `beautifulsoup4` (incluídas em requirements.txt)
2. Converta HTML para Markdown usando `html2text`
3. Preserve links e estrutura original
4. Adicione metadata (fonte, data de acesso)

## Engenharia de Contexto - Copilot

Para este diretório, use parâmetros de **Análise/Transcrição**:
- Top-k: 15-35 (diversidade moderada)
- Top-p: 0.4-0.6 (sampling equilibrado)
- Temperature: 0.3-0.5 (criatividade controlada)

Foco em: Síntese de informação, manutenção de contexto.
