# Transcrições de Vídeos

Este diretório contém transcrições de vídeos convertidos em texto.

## Estrutura

```
/videos
  ├── transcript_video1.md
  ├── transcript_video2.md
  └── README.md           # Este arquivo
```

## Como Adicionar Transcrições

1. Use ferramentas como `youtube-transcript-api` (incluída em requirements.txt)
2. Converta o conteúdo para Markdown
3. Adicione contexto e timestamps quando relevante

## Engenharia de Contexto - Copilot

Para este diretório, use parâmetros de **Análise/Transcrição**:
- Top-k: 15-35 (diversidade moderada)
- Top-p: 0.4-0.6 (sampling equilibrado)
- Temperature: 0.3-0.5 (criatividade controlada)

Foco em: Fidelidade ao conteúdo, estruturação clara.
